# 文档导航

按任务查阅本页；简单且上下文充分的任务直接执行，无需固定阅读流程。涉及用户偏好时查 [用户上下文](context.md)，需要沉淀或修正方法时查 [知识沉淀](memory.md)。同一会话不重复读取未变化的内容。

| 文档 | 用途 |
| --- | --- |
| [用户上下文](context.md) | 已确认的目标、偏好、工具与待确认项 |
| [知识沉淀](memory.md) | 什么值得记、放在哪里、如何更新和检索 |
| [技术架构](architecture.md) | 技术选型、模块边界和演进条件 |
| [工作区](workspaces.md) | 任务隔离、进度记录和恢复方法 |
| [自动化与集成](automation.md) | 能力现状、授权约定、持续工作的实现路径 |
| [工作观察方案](observation.md) | 全天观察、及时理解的最小推进方案与待验证边界 |
| [Telegram 工具](telegram.md) | 用户账号登录、结构化消息读取、草稿及经允许的发送 |
| [知识索引](knowledge/kb.index.v2026-11-11-220442.md) | 长期经验、决策及来源；新增可复用方法在此补充入口 |

本目录固定路径文档承担操作入口；`knowledge/` 存放长期知识，默认原地更新并由 Git 留存历史；`assets/` 平铺存放附件。业务项目自身文档留在对应项目，Luna 只记录必要链接和可复用结论。
